# Word 文档生成（.docx）

工具：`word__create`（生成）、`word__read`（回读核对）、`word__edit`（改写已有文档的段落，
另存副本）。都在工作区内生效，路径用相对路径或 `@user/` `@session/` 前缀；写的是磁盘上同一个
文件，「我的空间」里下次打开即见新内容。

## 什么时候用

- 用户要一份**能直接发出去的 Word**：报告、方案、合同、说明书、会议纪要、工作总结。
- 用户要**把内容变成排好版的 docx**（标题层级、表格、封面、目录、页码）。
- 要核对刚生成的 docx 内容对不对 → `word__read` 回读。
- 要在**已有** docx 上改几段文字 / 补一段说明 → `word__edit`（只动段落，另存副本）。

## 流程

1. **先想清楚结构再动手**：把内容拆成「封面 / 目录 / 一级章节 / 表格 / 附录」，
   一次性把 `blocks` 写全。分多次调用生成会得到多份文件、而不是一份连续的文档。
   **同时定版式**：公文 / 合同 / 报告 / 技术文档选一套（`preset`），别让模型自己
   猜字号行距。
2. **调用 `word__create`**：`path` 给输出路径（如 `报告/2026年度总结.docx`），
   `doc` 给结构描述。**排版由插件负责**，你只描述内容与层级。
3. **回读核对**：`word__read` 读回来看结构对不对（标题层级、表格内容、有没有漏块）。
4. **告知用户两件事**：文件路径；以及「目录与页码是 Word 域，在 Word 里按 `Ctrl+A` 再按 `F9`
   才会生成/刷新」。

## 改已有文档（word__edit）

只支持**段落**这一级，且**一律另存副本，不覆盖原件**：

| op | 字段 | 说明 |
|---|---|---|
| `append` | `text` `after`(可选) `style`(可选) | 追加一段。不给 `after` = 追加到文末；`after:0` = 插到最前；`after:N` = 插在第 N 段后 |
| `replace` | `index` `text` | 把第 `index` 段的**纯文本**换掉（保留段落样式与首个 run 的格式；段内的加粗/颜色等分格式会丢） |
| `delete` | `index` | 删掉第 `index` 段 |

要点：

- **段号口径**：正文里的第 N 个段落（1 起，**不含表格里的段落**），与 `word__read` 读出的顺序一致。
  先 `word__read` 看清段号，再动手。
- **ops 按顺序执行**，每做一步段号会平移——所以一次调用里想清楚顺序，别指望段号是固定的。
- 表格内部、图片、页眉页脚、批注、修订一律不动。
- 输出默认 `<原名>_edited.docx`；`out_path` 可以另指定，但**不能与原文件同名**（会被拒绝）。
- 改完用 `word__read` 回读核对。

## 版式预设（preset）

排版规范不是让模型自己想，是**整套给定的**。模型只要说一句"按合同版式"：

| preset | 中文名 | 排版规范 |
|---|---|---|
| `gongwen` | 公文 | 三号（16pt）仿宋、固定行距 28 磅（每页 22 行）、首行缩进两字符、段后 0、两端对齐；一级标题三号黑体、二级三号楷体加粗、三四级三号仿宋加粗；版心 156×225mm（页边距 上 3.7 / 下 3.5 / 左 2.8 / 右 2.6 cm） |
| `contract` | 合同 | 小四（12pt）宋体、1.5 倍行距、首行缩进两字符、段后 6pt、两端对齐；文档标题 18pt 居中；一级标题 16pt 黑体…；页边距 上下 2.54 / 左右 3.17 cm |
| `report` | 报告 | 小四（12pt）宋体、1.5 倍行距、首行缩进两字符、段后 6pt、两端对齐；标题 22pt 黑体居中；一级标题 16pt 黑体…；页边距 2.5 cm；**默认带目录** |
| `tech` | 技术文档 | 微软雅黑 11pt、行距 1.4、**不首行缩进**（靠空行分段）、段后 8pt、左对齐；标题 20pt 居中；一级标题 18pt…；代码块 10pt Consolas；**默认带目录** |
| `default` | 默认 | 不指定时的老样子 |

写法（`preset` 放在 `doc` 里或顶层都行，中文名也认）：

```json
{ "path": "合同/服务协议.docx", "preset": "contract",
  "doc": { "title": "技术服务合同", "blocks": [ ... ] } }
```

**预设是默认值，不是强制**：`font_ea` / `font_ascii` / `page.size` / `page.margin_cm` /
`title_size` 你显式写了就以你的为准。列表、表格单元格里的首行缩进会被自动清零
（正文缩进、表格不缩进）。

## 结构描述怎么写

`doc.blocks` 是**按顺序渲染**的块数组，块的 `type` 决定写法：

| type | 关键字段 | 说明 |
|---|---|---|
| `heading` | `text` `level`(1-4) | 标题。level=1 是一级章节；`page_break_before:true` 可让它另起一页 |
| `paragraph` | `text` | 正文段落。`bold` `italic` `align` `size` `indent` 可选 |
| `bullets` / `numbers` | `items[]` | 无序 / 有序列表 |
| `table` | `header[]` `rows[][]` | 表格。表头自动加粗带底纹、跨页重复；`widths_cm` 给列宽；`caption` 图题 |
| `image` | `path` `width_cm` | 插图（图片路径也要在工作区内）；`caption` 图题 |
| `code` | `text` | 代码块（等宽灰底） |
| `quote` | `text` | 引用块（缩进 + 左侧竖线） |
| `caption` | `text` | 独立的说明文字 |
| `page_break` | — | 分页 |
| `spacer` | `count` | 空行 |

顶层还有：`title` `subtitle` `cover`（封面页：标题/副标题/作者/日期/单位）、
`page`（`size`: A4/LETTER/A3、`margin_cm`）、`header`（页眉文字）、`footer`（`page_numbers`
页码域）、`toc`（目录：`enabled` `levels` 如 `1-3` `title`）。

一个完整例子：

```json
{
  "path": "方案/产品方案.docx",
  "doc": {
    "cover": { "title": "产品方案", "subtitle": "v1.0", "author": "产品部", "date": "2026-10-28" },
    "toc": { "enabled": true, "levels": "1-2", "title": "目录" },
    "header": { "text": "内部资料 · 请勿外传" },
    "footer": { "page_numbers": true, "prefix": "第 ", "middle": " 页 / 共 " },
    "blocks": [
      { "type": "heading", "level": 1, "text": "一、背景" },
      { "type": "paragraph", "text": "……正文……" },
      { "type": "heading", "level": 2, "text": "1.1 现状" },
      { "type": "bullets", "items": ["要点一", "要点二"] },
      { "type": "table", "header": ["指标", "现状", "目标"], "rows": [["留存率", "31%", "45%"]], "widths_cm": [4, 5, 5], "caption": "表 1 核心指标" }
    ]
  }
}
```

## 禁区

- **只读工作区**下不能写——会被拒绝；先确认工作区可写。
- **不要覆盖用户已有文件**：`path` 指向已存在的文件时，插件会拒绝并报错；确实要覆盖就加
  `"overwrite": true`，并**先提醒用户**。
- **不要用 `word__create` 改已有文档**：它是「从零生成」，会丢原文档的样式/图表/批注。
  要改已有文档用 `word__edit`，但它只支持段落级的三种操作；超出这个范围（如改表格内容、
  动图片、留修订痕迹）就如实说明，让用户在 Word/WPS 里改。
- **`word__edit` 不覆盖原件**：这是硬约束，别试图用 `out_path` 指回原文件（会被拒绝）。
- **图片路径必须在工作区内**，且必须是真实存在的图片文件；不存在会报错。
- **目录与页码是 Word 域**：不更新域，目录位置显示的是提示文字而不是条目。提醒用户按
  `Ctrl+A` → `F9`，或别承诺「目录已经填好了」。
- **别自己发明排版**：字号、行距、页边距交给 `preset`。你显式写 `font_ea` 等
  参数时以你的为准，但别只写一半（只改字号不改行距会不协调）。
- **一次别塞太满**：内容特别长时按章节分块，但要注意多次调用会生成**多个文件**——
  要一份连续文档，就得在一次调用里把 blocks 写全。
- 不支持：批注、修订留痕、公式、图表、SmartArt、文本框、宏（.docm）。需要这些时如实说明，
  不要硬凑。
